# 孩子端答题流程优化方案（第五期草案）

日期：2026-10-03　基于 `uat` 分支提交 c64811b　状态：方案第二版，已按家长 10/3 的决定修改，等确认后实现

可点原型（第二版）：https://claude.ai/artifact/G74hTZF1gMd6KvJMaxcfbN（拼算式、分步应用题、竖式三道示范题，右侧可以改本领等级、补满次数）

**家长 10/3 定下的（详见第 7 节）**：本领按等级限次数，孩子点了才用；整道题做完再判，中间不打断；被 3 级守护接住的那次不算首答正确；用了 2 级帮忙没有过程奖；口算每天默认 5 到 7 题。

和「宠物养成优化方案」（`docs/宠物系统优化方案.md`）分工：那边管本领列表、技能点和升级节奏、小屋里的把戏；这边管**本领在答题时怎么出现、怎么起作用**，以及题目本身的作答步骤。技能点来源和成本以宠物方案为准。

## 1. 现在的问题

### 1.1 作答步骤是按题型写死的，新题型接不进来

现在 9 种题型，每种的步骤都写死在四个地方：`contract.js` 的 `instantiate()` 和 `publicItem()`、`game.js` 的 `answer()`、`main.js` 的 `vQ()`。应用题固定是「圈关键词 → 选算式 → 算和答」，挑战题固定是「先求什么 → 选算式 → 算和答」。

对照 `知识点.md`，这学期后面的单元大多接不进来：

| 单元 | 要怎么答 | 现在能不能做 |
|:--|:--|:--|
| 02 两、三位数乘一位数（已学过，错题复习还会用到） | 列竖式，个位起一位一位乘，记进位 | 不能。只能出口算或先估后算，孩子在屏幕上没处写竖式 |
| 06 两、三位数除以一位数 | 竖式除法，商中间有 0、末尾有 0，有余数 | 不能。答案只能是一个整数（`okAnswer`），「商 7 余 2」没法表示 |
| 04 毫米、分米和千米 | 单位换算、复名数（3 千米 200 米） | 半能。多空题能填数，但答句只有一个数一个单位 |
| 01.4、07 两步计算的实际问题、数量关系分析 | 分两步列式，每步说清求什么，有时还要合成综合算式 | 半能。挑战题只选「先求什么」，算式仍是一个现成的综合算式，中间量从来不用孩子算出来 |
| 03 数据的收集与整理（**正在学**，家长 10/3 确认） | 看统计表、图表填数、比较 | 只能用多空题硬套，表格和图表显示不出来。具体题型等家长给材料后再定 |
| 05 平移旋转轴对称、08 观察物体 | 看图选、在方格上画 | 不能，没有图 |

### 1.2 「选算式」可以猜

应用题和挑战题都是三选一。选错一次后只剩两个，订正还能拿五成金币。孩子很可能学会「先随便点一个」，而这正是我们要纠正的抢快。屏幕首答率也因此偏高。

### 1.3 本领在答题里几乎看不见

- 本领等级在答题时只有一处效果：灵鼻子 1 级以上，圈完关键词的反馈后面多半句「灵鼻子也嗅出来了」（`main.js` 157 行）。其他五个本领、所有 2 级 3 级，在答题里没有任何区别。
- 答题页右上角的小圆环写着「3/5 技能点」，孩子不知道是什么意思（这是「同一错因、略变以上难度第一次就对 5 题得 1 点」）。
- 小狗头像只有三种表情（开心、思考、骄傲），不跟着步骤变化。

### 1.4 其他

| 问题 | 现状 |
|:--|:--|
| 错了的反馈不分错法 | 第一次错一律显示模板的 `hint`，第二次一律显示 `explain`。孩子选的是哪个陷阱、错在哪，程序其实知道（`traps` 里有错因），但没有用来说话 |
| 讲解只有一段文字 | 错三次后显示 `explain` 就结束，孩子最后没有把这道题正确地做一遍 |
| 圈关键词和列式脱节 | 圈完对一下就过去了，下一步选算式时圈的东西没有用处 |
| 算和答一步跳太远 | 选好 `100 − 12 × 3` 以后直接要最终得数，中间一步只能心算或者另找纸 |
| 结算只讲金币 | 每题结算是「＋12 第一次就答对了」，没说他做对了哪个习惯 |
| 技术上加题型贵 | 每加一种要改四处，每种的进度各存一套字段（`kwRes`、`expr`、`pub`） |

## 2. 方案一：题目由「步骤积木」拼成

把作答拆成几种可以复用的步骤，题型只是常用的组合。模板可以直接写 `flow`，不写就用题型的默认组合，现有模板一个不用改。

### 2.1 积木

| 积木 | 孩子做什么 | 判分 | 来源 |
|:--|:--|:--|:--|
| 圈 `circle` | 在题干上点关键词 | 关键词全中、多圈几处 | 现有 |
| 选 `pick` | 几个选项里点一个（先求什么、范围、哪一行错、先算哪个符号） | 对不对 | 现有，合并 `goals` `ranges` `first` `fix` 的找错行 |
| **列式** `build` | 点题干里的数（圈过的数会变成数字卡）加上 ＋ − × ÷ （ ），自己拼出算式 | 算出来的值对，并且用到的数对。`100 − 12 × 3` 和 `100 − 3 × 12` 都算对；只拼出 `12 × 3` 会被告诉「这只算出了买彩笔花的钱」 | 新，替代三选一 |
| **递等式** `chain` | 按孩子自己列的式子一行一行算：每行先点自己要先算的符号，再填得数，下一行照他的选择生成 | 每行先算的对不对、算得对不对，能认出「从左往右算」 | 现有 `steps` 和 `first` 合并，改成自动生成，不用模板写 `lines` |
| **竖式** `column` | 在格子里从个位起填，进位、退位有小格 | 每一位对不对；能认出「忘加进位」「商的中间漏 0」「余数比除数大」 | 新 |
| 填 `fill` | 键盘填一个或几个数 | 现有 | 现有，合并 `oral` `multi` |
| **答句** `say` | 「答：……□ □」，单位单独一格；可以是两格数（商和余数、千米和米） | 数对、单位对 | 现有，扩展成多格 |
| **验算** `check` | 做完再检查一次：估一估、用乘法验除法、把得数代回题目 | 对了给过程奖 | 新，可选 |
| 看图选 `figure` | 选项是程序画的图（方格上的图形、立体图的几个方向、条形图） | 对不对 | 新，最后做 |
| **统计表** `table` | 看记录（正字或 ✓）点格子填数，合计也自己填 | 每一类数对不对、合计等不等于各项之和 | 新，03 单元 |
| **点数据** `tapnum` | 从一串数里点出符合条件的数（超过 20 分的、最高的），下面填个数 | 点得对不对、数得对不对；能认出「把 20 也算进超过 20」 | 新，03 单元 |
| **边看边记** `tally` | 程序转转盘或摸球，每出一个结果孩子在对应那一类上添一笔正字 | 最后每类的笔数对不对 | 新，03 单元，可选 |

### 2.2 新的组合

- **应用题（拼算式版）**：圈 → 列式 → 递等式 → 答句。列式有三档，跟着孩子最近的状态升降，不固定：

  | 列式档位 | 孩子做什么 |
  |:--|:--|
  | 0 选算式 | 三个算式里选一个（现在的做法） |
  | 1 拼算式 | 只给要用的数字卡，自己拼 |
  | 2 拼算式加干扰 | 多给一张用不上的数字卡（比如噪音句里的数） |

  每个「知识点 × 错因」新出现时从第 0 档开始，不会一上来就是最难的。升降沿用现在的难度阶梯规则：最近 10 题首答 ≥85% 且跨两天升一档，最近 8 题 <60% 或连错 3 题降一档。和题目本身的难度（同构、略变、综合）各算各的，但第 2 档只在略变以上的题出现。
- **分步应用题** `multi-step`：每一步都是「这一步求什么（选）→ 列式 → 得数和单位」，上一步算出的数变成下一步的数字卡（「下午 90 本」）。最后写答句；01.4 和 07 需要的话再加一步「合成综合算式」。现在的挑战题并进来，只是第一步多一个「先求什么」。
- **竖式题** `column`：乘一位数、除以一位数、三位数加减。模板只写算式，格子由程序排。可以接验算。
- **复名数 / 有余数**：答句两格，`商 □ 余 □`、`□ 千米 □ 米`。`okAnswer` 放开到「几个非负整数」。

### 2.3 整道题做完再判，中间不打断

现在每一步做错都会马上被拦下来给提示，最多错三次。改成：

- 每一步只收孩子的作答，不说对错，直接进下一步。列错了式子，递等式就照他列的式子算；第一步得数写错了，第二步的数字卡就是他写的那个数。
- 只有「格式上做不下去」才提示，比如算式没写完整、括号不成对、得数没填。
- 交卷后一次性给评价：每一步对不对、错在哪、归哪个本领管，然后给出正确做法。因为每一步都按他自己的结果往下走，能分清是**列式错**还是**计算错**，比现在只看最后得数准确。
- 答错的题不给金币（家长 10/3 定），可以「跟着正确做法再做一遍」（不计金币），过两天换个样子再来。原来的订正五成、错两次三成取消。
- 「急着答错」按整道题的用时判。

### 2.4 模板怎么写（rules.md 第 9 节要跟着改）

```json
{ "id": "t31", "format": "word", "flow": ["circle", "build", "chain", "say"], "segs": [...], "nums": ["{a}", "{b}", "{c}"],
  "answer": "{a}-{b}*{c}", "traps": [{ "e": "({a}-{b})*{c}", "error_type": "概念不清", "say": "是不是从左往右算了？有减有乘，先算乘法。" }] }
{ "id": "t32", "format": "column", "expression": "{a}×{b}", "check": "estimate" }
```

每个陷阱可以带一句 `say`，孩子答成这个数，交卷后的评价里就说这句，不再一律显示 `hint`。`hint` 改由本领 1 级提醒使用。

口算热身组的 `daily` 默认改成 6（可在 5 到 7 之间调），rules.md 第 9 节和 `pickToday()` 的默认值跟着改。一天总题量仍约 20 题，重点组相应少一两题。

### 2.5 第三单元：统计表题（家长 10/3 给的课本第 38–39、44–45 页）

课本这一单元只有统计表，没有条形图，所以 `figure` 不用提前做。例题拆下来是四类：

| 课本里的题 | 屏幕上怎么做 | 积木 | 例子 |
|:--|:--|:--|:--|
| 按记录填统计表 | 题干给正字或 ✓ 的记录，孩子填各类人数和合计 | 统计表 | 最喜欢的水果、童话种类、秋游地点（✓）、球类（正字） |
| 读表回答 | 最多、最少是哪类：选；一共、相差、多多少、少多少：拼算式 → 答句 | 选、列式、答句 | 「最喜欢科幻童话的比最喜欢动物童话的多多少人」 |
| 整理一串数据 | 点出符合条件的数，再数个数；最高、最低：点一个 | 点数据、答句 | 篮球 30 场得分：超过 20 分的有几场，超过 30 分的呢 |
| 同一份记录按两种方法分类 | 两张统计表各填一次 | 统计表 × 2 | 停车场：按车型分、按停车时间分 |

一道统计题通常是「先填表，再答两三个小问」，所以按**小问**判分、给金币：表填错了，后面的小问照着孩子自己填的数往下走（数字卡就是他填的数），交卷时分开说「表里羽毛球数错了」和「这一问方法对」。一题的金币上限和同难度的应用题差不多，只是拆到每个小问，答错的小问不给。

常见错法和归哪个本领管：

| 错法 | 本领 |
|:--|:--|
| 正字数错（一个正是 5，剩下几笔没数对） | 稳稳爪 |
| 合计不等于各项之和、漏填一格、点数据漏点或多点 | 巡逻 |
| 「超过 20」把 20 也算上、最多最少看反、比的不是题目问的两类 | 灵鼻子 |
| 相差用小数减大数 | 排排队 |
| 答句单位写成「种」「分」 | 收尾巴 |

本领在这几步的效果：稳稳爪 1 级提醒「一个正字是 5」，2 级把记录按 5 个一组框出来；巡逻 1 级看空格，2 级陪你把各项加起来和合计对一对，点数据时 2 级把数从小到大排好；灵鼻子 1 级提醒「超过」算不算 20 本身。

不放到屏幕上的：转转盘、摸球求和、量一庹长和身高、调查兴趣小组，这些要孩子真的动手，留给课堂和纸面；「你能提出哪些问题」「你建议去哪里」这类开放题也不做。转盘和摸球可以用 `tally` 在屏幕上模拟（程序转 20 次，孩子边看边记正字，记完填表），排在 5B 最后，做不做到时候看孩子的兴趣。

模板写类别、数的范围和小问，数字每次随机生成，各类人数不并列（除非题目就是考并列）：

```json
{ "id": "t41", "format": "stat", "record": "tally", "cats": ["乒乓球", "羽毛球", "篮球", "排球", "足球"], "vals": "3..15",
  "asks": [{ "flow": ["pick"], "ask": "max" }, { "flow": ["build", "say"], "ask": "max-min", "unit": "人" }] }
{ "id": "t42", "format": "data", "nums": "12×(10..38)", "ask": "over", "over": [20, 30], "unit": "场" }
```

原型里有「统计表」和「整理数据」两道示范题。

## 3. 方案二：本领由孩子点了才用（「本领徽章」）

### 3.1 三档，按等级限次数

答题页底部的**陪伴条**上，亮出这一步用得上的本领徽章。小狗不会自己出手，孩子点徽章，弹出一个小菜单，选这次用哪一级：

| 等级 | 叫法 | 效果 | 次数（每个本领单独算） |
|:--|:--|:--|:--|
| 1 级 | 提醒 | 说一句**不泄露答案**的提醒 | 每天 3 次 |
| 2 级 | 帮忙 | 帮一个具体的忙（3.2 表里） | 每天 1 次。用了这题没有过程奖，金币照常 |
| 3 级 | 守护 | 守着这道题：交卷时如果错在它管的地方，先拦下来，告诉他错在哪一步，回去改这一步再交 | 每周 1 次。没用上（这题没错在它管的地方）就退回次数 |

学会 3 级的本领，菜单里 1、2、3 级都能选；高等级用完了，低等级还能接着用，直到用完。原则是用得少、不自己出手、每次用都有点新鲜。

被守护接住的那道题，**不算首答正确**，家长端单独记一行「被接住」；孩子这边金币照给，连击不断。一道题只能有一个本领守着。

### 3.2 每个本领

守护按陷阱和判分时的错因归类：审题→灵鼻子，运算顺序→排排队，计算→稳稳爪，单位→收尾巴，漏填→巡逻，先求什么→探路。

| 本领 | 徽章出现的步骤 | 1 级 提醒 | 2 级 帮忙 | 3 级 守护：交卷时拦下 |
|:--|:--|:--|:--|:--|
| 灵鼻子（审题） | 圈、列式 | 问题那句下面留一串小脚印：「先看它问什么」 | 把一句用不上的话变灰 | 列式用错了条件、只算了一步 |
| 排排队（运算顺序） | 列式、递等式 | 「有括号先算括号里的，没括号先乘除后加减」 | 递等式里给先算的那块标 ① | 递等式里先算错了顺序 |
| 稳稳爪（计算） | 递等式、答句、竖式 | 「交之前估一估，大概几位数？」 | 说出这一行得数是几位数；竖式里要进位的格子亮出爪印 | 算错了数、竖式忘加进位 |
| 收尾巴（答句单位） | 答句 | 「写完从头读一遍答句」（不指出单位格，和 `unit_hint=0` 不冲突） | 把答句读出声，读到空着的地方停一下 | 忘写单位、单位写错 |
| 巡逻（检查） | 答句、竖式、多空题 | 看看还有几个格子空着 | 陪你验算（估算，或把得数代回题目） | 有格子空着就交卷 |
| 探路（策略） | 先求什么、分步应用题 | 「这题要走两步」 | 在「先求什么」里划掉一个走不通的 | 先求的东西选错 |

### 3.3 让升级被看见

1. **陪伴条**取代右上角的小头像和「3/5」圆环：左边是小狗（跟着步骤换表情），中间是它说的话，右边是这一步用得上的本领徽章，徽章下面是等级点；正在守护的徽章亮蓝圈、写「守护中」。还有次数可用的徽章亮橙圈，用完了变灰。没学会的本领不出现。
2. **菜单**里每一级写清楚这一步它能做什么、今天或这周还剩几次，用不上的那一级写原因（「这一步用不上」「今天的次数用完了」）。
3. **本领发动**有一个短动画：徽章弹一下，顶部飘出「灵鼻子 2 级 · 帮忙」。守护接住时是整屏的「稳稳爪接住了！」。
4. **学会新等级时**，本领页的仪式后面加一个「试一试」：用一道固定的示范题停在这个本领用得上的那一步，菜单直接打开，这一次不扣次数。
5. **每题结算**列出「本领帮了你」「被接住了一次」「守护没用上，次数退回了」；**当天结算**多一栏「今天用了几次本领」。
6. **技能点的来源**改成「做出这个习惯就得」（宠物方案已采纳）：圈得刚刚好→灵鼻子，单位第一次就写对→收尾巴，竖式进位全对→稳稳爪，递等式先算的对→排排队，先求什么第一次就对→探路，巡逻不变。每个本领攒满 `SKILL_EVERY[本领]` 次习惯得 1 点，每天最多 1 点，常练的本领约第 2–3 周到 1 级、第 6–8 周到 2 级、第 12–14 周到 3 级。数值以宠物方案为准。两边约定：效果随级数变强，但不替孩子做掉要练的那一步。

### 3.4 不变的原则

不计时、不奖励速度；本领不直接给答案、不自己出手；次数少；不扣金币。

## 4. 方案三：其他改进

1. **错法对应的评价**：陷阱带 `say`，交卷后孩子答成哪个陷阱就说哪句；拼算式拼成中间量时说「这只算出了……，问题问的是……」。
2. **讲解变成「跟着做一遍」**：答错的题，交卷后先给正确做法，再可以用自动生成的递等式（或竖式）一步一步带着他填完，不计金币。孩子每道题最后都亲手做对一次。
3. **结算讲习惯**：每题结算先说「圈得刚刚好」「单位第一次就写对」「进位全对」，再说金币。
4. **读题**（可选调节项 `read_aloud`，默认关）：题干旁边一个喇叭，用浏览器自带的中文朗读。家长觉得孩子读题吃力时再开，审题训练期间别开。
5. **草稿纸**：答题页底部一个「草稿」按钮，弹出一块可以写画的板，不保存、不判分。有了竖式积木后用得少，但口算和递等式还用得上。
6. **按 iPad mini 竖屏排版**（家长说主要用它，744 × 1133）：和宠物方案第 3 节用同一套约定，`.app` 最宽 744，字号按家长要的再大一些（正文 20、小字不小于 15、气泡 21、按钮 24、页面标题 35，题干不小于 22），可点区域至少 48 高，弹层是居中卡片、最宽 580，手机宽度（600 以下）退回一栏。答题页面上，数字键盘和数字卡按钮放大到 56 左右，统计表和竖式格子按宽屏加大，题干和作答区在宽屏上不用挤成一列滚动。
